# Open Broadcast 0.1.1

One-click, in-place Windows updates, with clearer controls and safer cancellation.

## What's changed

- Added **Update and restart** to the control panel and tray menu for installed Windows builds. One click checks GitHub for a newer stable release, downloads its installer, verifies its SHA-256 checksum, upgrades and relaunches.
- Upgrades explicitly target the running app's installation directory, including custom install paths. Existing settings are preserved.
- The update controls are disabled while checking or downloading to prevent duplicate requests. Downloads can be cancelled before installation, including immediately after a download completes.
- Failed downloads or installer-launch errors keep the app open instead of exiting into an incomplete update.
- Automatic background checks still require confirmation before installation. The existing **Check now** and **Install and restart** flow remains available, and manual updates work even when automatic checks are disabled or a version was skipped.
- Added regression tests for the one-click flow, control visibility, busy state, cancellation, failures and installer arguments.

`SHA256SUMS.txt` contains checksums for all release downloads. No Intel macOS, Windows ARM, Linux ARM, `.deb` or `.rpm` packages are included.

## Upgrading from 0.1.0

In an installed Windows 0.1.0 build, choose **Check now** in the control panel or **Check for Updates...** in the tray menu, then **Install and restart**. The app verifies and installs this release while retaining your settings. Once on 0.1.1, use the dedicated **Update and restart** button for future releases.

Portable, macOS and Linux users should download the matching package and replace their existing app. An update check opens the release page on these builds; they do not install updates automatically.

## Requirements and limitations

- Windows binaries are unsigned. The macOS app is ad-hoc signed, not Developer ID signed or notarized; operating-system security warnings may occur.
- In-place installation is supported only by the Windows installer build. Prereleases are not offered by the normal update check.
- Virtual microphone and camera drivers are not bundled. Windows audio routing requires a virtual device such as VB-Audio Virtual Cable; macOS can use BlackHole. Camera output requires a compatible virtual-camera backend.
- Automated audio and model checks do not replace listening or real-call testing with your own devices.

## Release verification

The release workflow validates the source version and curated notes, runs the unit tests on Windows x64, macOS ARM64 and Linux x64, then builds and smoke-tests the frozen app on each platform before publication. Source version `0.1.1` must match tag `v0.1.1`. The Windows installer download is checksum-verified before the app launches it.

# Open Broadcast 0.1.2

Tune your microphone effects and compare a recording before joining a call.

## What's changed

- Added adjustable noise-removal strength, voice-gate hold time, and an optional 80 Hz low-cut filter for rumble.
- Added **Test your voice**: record up to 10 seconds, play or pause, seek, and switch between aligned Original and Processed recordings. Effect changes re-render the clip.
- Organized the control panel into Microphone, Speaker, and Camera tabs, with shared processing controls and application settings. Speaker processing is marked unavailable.
- Tightened microphone-panel spacing so the default window fits on Windows, macOS, and Linux.
- Fixed preview audio-stream cleanup when a device fails to start, with regression coverage.

## Upgrading

Installed Windows 0.1.1 users can select **Update and restart**. Settings are preserved. Portable, macOS, and Linux users should download the matching package and replace the existing app.

Virtual audio and camera drivers remain separate installations. Preview playback uses your default output device. Automated tests cover the audio processing and playback logic; listening and real-call testing with your own devices remain recommended.
